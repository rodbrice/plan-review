# C2: rules R3 to R5, configuration, Markdown and JSON reports

Date: 2026-11-12

## What this milestone delivers

- `src/plan_review/iam.py`: parser for IAM policy documents (single statement or list,
  string or list fields, `Principal` as a string or an object) and the list of wildcard
  grants an `Allow` statement makes, as action and resource pairs.
- `src/plan_review/exposure.py`: what R4 and R5 compare: ports open to `0.0.0.0/0` or
  `::/0`, public-access settings, public canned ACLs and bucket policy statements for
  anyone.
- `src/plan_review/rules.py`: R3 (IAM policy widened), R4 (ingress open to the world),
  R5 (bucket made public). Each reports only what is new in `after` compared with
  `before`.
- `src/plan_review/config.py`: `.plan-review.yml` with `ignore` and `severity`, validated
  strictly.
- `src/plan_review/report.py` and `src/plan_review/cli.py`: `--format text|markdown|json`;
  the command reads `.plan-review.yml` from the current directory.
- `src/plan_review/model.py`: loads `before_sensitive` and `after_sensitive` again, so a
  rule can avoid quoting a sensitive policy document or port.

No new sample plan was needed: `iam_widened` and `exposure`, generated in C0, already
contain a positive and a negative case for each rule.

## Acceptance

| Criterion | Where it is checked |
|-----------|---------------------|
| R3 positive and negative cases | `tests/test_rules_r3_r5.py`: widened and new policies; narrowed policy, wildcard already granted, other types, deletion |
| R4 positive and negative cases | same file: world-open IPv4 and IPv6 rules, `aws_security_group_rule`, inline blocks, a port known only after apply; private rule, rule already open or narrowed (port range, all traffic, ICMP type or code), deletion, egress |
| R5 positive and negative cases | same file: settings turned off, block destroyed, public ACL, public bucket policy; new block, setting already off, `forget`, public ACL narrowed, conditional or scoped policy |
| IAM policy parser | `tests/test_iam.py` |
| Configuration ignores a rule and changes a severity | `tests/test_config.py` and the configuration tests in `tests/test_cli.py` |
| Markdown and JSON reports | `tests/test_cli.py` |
